Windows fences agents while ChatGPT adds buttons

Prompt Daily, Episode 009. Thursday, 8 October 2026, looking back at Wednesday, 7 October 2026. Maya and Ravi are AI voices. Produced by LumeGrid. Runtime: 9 minutes 51 seconds. Nothing here was retested.

Windows

Microsoft Execution Containers are generally available. On Windows 11, Microsoft says an organization can limit the files and networks an agent may use, and Windows enforces that at runtime when enforcement is on. Permissive mode records otherwise-denied operations but allows them. Codex and GitHub Copilot are among the agents Microsoft says already support it. Also named: OpenClaw, Replit, LM Studio, NVIDIA OpenShell, and Unsloth. Claude Code, Perplexity, Raycast, Box, and others are named as support still to come. A Windows session can use a separate account. Entra identity in Agent 365, and Intune policy for process containers, are described as coming soon. Copilot local context, local actions, and local models are announced for Copilot+ PCs, with permission, and expected to begin rolling out in the coming months. That is the named target, not a feature Microsoft says is on every Windows PC now. Search actions start with Insiders on the experimental channel. Copilot inside Search is opt-in, selected markets, later this year. Surface Laptop Ultra is available beginning 16 October 2026, up to 128 GB of memory. Microsoft says it can run models past 120 billion parameters. The Surface RTX Spark Dev Box ships to U.S. customers in November. ASUS, Dell, HP, Lenovo, and MSI RTX Spark laptops are on Microsoft's 16 October window. MAI Code quality after compression is Microsoft's claim. HydraFusion using local models is an experimental preview later in October for the GitHub Copilot app, GitHub Copilot CLI, and Visual Studio Code. Also announced, and not all spoken: llama.cpp on Windows ML, an upcoming Nemotron, DeepSeek V4 Flash, Muse for Windows coming soon, and DGX Station for Windows later this year.

ChatGPT

The GPT-6 rollout with Intelligent UI began 7 October 2026 for Plus, Pro, Business, and Enterprise in Chat. Free and Go were set for 8 October 2026. Enterprise depends on the admin. Paid Chat uses GPT-6 Sol. Free and Go use GPT-6 Luna. Work and Codex models do not change. The Pro reasoning option still uses GPT-6 Astra and does not get Intelligent UI. Instant through Extra High do. Answers may mix text with graphics, buttons, forms, charts, and small tools, or stay plain text. OpenAI's speed figures, including a 44 percent sooner start on its own search test, and its 1.2 billion weekly-user figure, were not rerun.

Haiku 5.5

Available 7 October 2026. Model id claude-haiku-5-5. One million tokens of context. Up to 100,000 prompt tokens: 10 cents per million input and 50 cents per million output. Above that: 50 cents and $2.50. The 90 percent sticker cut is the short tier against Haiku 4.5. The long tier is half off. Anthropic says about 90 percent of older Haiku requests were short, and estimates about 75 percent average savings after a tokenizer the docs say uses about 30 percent more tokens for the same text. Sonnet 5.5 cache reads move from 20 cents to 10 cents per million. About 20 percent off most agent work is Anthropic's estimate. Max and Team API credits roll out over a few days: $100, $200, and up to $500 pooled, after linking a Console organization. Anthropic says cyber safeguards are stricter than Haiku 4.5 and still block penetration testing.

Biology

Wednesday expands the Virtual Biology Initiative announced in April 2026. Biohub's body says $1.8 billion across funding, data, compute, and measurement tools. The headline says nearly $2 billion. NIH's piece is datasets from more than $500 million in prior federal investment, not a new cash check. DOE says more than $500 million over five years. Biohub's $500 million is the April commitment, including cryo-electron tomography in the measurement share. DeepMind, Isomorphic Labs, and Meta commit $300 million together. No new public dataset is in the posts. DOE calls the work Super Intelligence.

SynthID

Google opened the detector to everyone, in English, worldwide, on 7 October 2026, for image, video, and audio watermarks from Google or from OpenAI, NVIDIA, Kakao, and Apple soon. A missing mark is not proof a person made the file.
